# Portfolio sites

- wachira-portfolio/  jungle green theme, leaves and fireflies background
- mahzil-portfolio/   dark space theme, starfield background

Each folder holds index.html, style.css and script.js. No build step or install needed.

## Run in VS Code
1. File > Open Folder... and choose portfolio-sites
2. Install the "Live Server" extension (Ritwick Dey)
3. Right-click a folder's index.html > Open with Live Server

You can also just double-click index.html to open it in a browser.

Note: the fonts load from Google Fonts, so you need internet for the intended typography.
